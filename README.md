# 报纸文章识别

把一份报纸扫描放进来，按版面把各篇文章拆开，并尽量分出标题、作者和正文。

## 怎么打开

1. 已装好 Python 3.11 后，在这个目录执行：

```
py -3.11 -m pip install -r requirements.txt
```

2. 双击 `run.bat`，或执行：

```
py -3.11 -m newspaper_app
```

3. 浏览器会打开 `http://127.0.0.1:8765/`。

## 怎么用

- 左边选一份报纸（`F` 或 `inbox` 里的 PDF / 图片），点「识别这一份」。
- 也可以点「放入报纸」上传新文件。
- 中间是版面，红框是拆出来的一篇。点框或右边列表可以改标题、作者、正文。
- 一篇被拆碎了，用「并入上一篇」。广告或误检用「删掉这一块」。
- 导出 TXT、Markdown 或 JSON。结果也会保存在 `output` 目录。

竖排报纸按从右到左、从上到下阅读。旧报纸扫描会有错字，请核对后再导出。重新识别会覆盖手工修改。
